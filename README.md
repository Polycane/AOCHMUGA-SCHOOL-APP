# AOCHMUGA SCHOOL MANAGEMENT SYSTEM
Motto: Hard Work Pays
Default location: Rangwe Subcounty, Homa Bay County, Kenya.

Starter Android project with an offline WebView prototype for learner registration, CBC-style grading, report preview, and editable learning areas.

This is NOT a production-ready Firebase/SMS/multi-school system yet. Build it in Android Studio to create an APK.
